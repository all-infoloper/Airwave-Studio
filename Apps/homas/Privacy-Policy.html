Kebijakan Privasi Homas

Homas Privacy Policy & Transparansi Pemrosesan Data Mandiri (Local-First Architecture)

shield

Pernyataan Inti Privasi: Local-First & Zero Server Telemetry

Aplikasi Homas dirancang dan dibangun dengan prinsip absolut Local-First. Semua basis data inventaris rumah, rincian barang, riwayat logistik, serta catatan tagihan operasional Anda tersimpan sepenuhnya di memori fisik perangkat lokal Anda. Developer Karsa Studio TIDAK memiliki server penyimpanan eksternal, tidak mengoperasikan repositori pusat, serta TIDAK MENGUMPULKAN, TIDAK MENJUAL, maupun MEMBAGIKAN data Anda kepada pihak mana pun.

01

Ruang Lingkup & Izin Akses Google Drive / Google Sheets

Dalam pengoperasian fitur lanjutan, aplikasi Homas dapat meminta izin akses ke akun Google Anda, khususnya cakupan Google Drive API dan Google Sheets API. Izin ini diatur secara ketat dengan parameter berikut:

cloud_sync Inisiatif Backup Eksklusif

Sinkronisasi hanya berlangsung ketika Anda menekan tombol cadangan secara sadar. Berkas hasil cadangan diunggah langsung dari gawai ke direktori Google Drive pribadi milik Anda sendiri.

table_view Ekspor Lembar Kerja (Sheets)

Fitur ekspor inventori menyusun lembar kalkulasi Google Sheets langsung di akun Google aktif pengguna. Developer tidak menerima salinan, tautan, ataupun token kredensial lembar tersebut.

*Homas tunduk sepenuhnya pada Google API Services User Data Policy, termasuk klausul Limited Use Requirements.

02

Kepemilikan Data & Ketiadaan Pelacak Pihak Ketiga

Hak kepemilikan intelektual dan data personal atas semua entri inventaris barang, foto aset, estimasi harga beli, serta konfigurasi zonasi ruangan adalah 100% milik pengguna.

  • check_circle Tanpa Cloud Sinkronisasi Developer: Tidak ada pertukaran protokol backend ke API server milik developer.
  • check_circle Tanpa Pelacak Analitik Invasif: Aplikasi tidak menyematkan pustaka analitik pihak ketiga yang merekam isi catatan Anda atau profil demografis rumah tangga.
  • check_circle Kerahasiaan Offline: Aplikasi beroperasi secara penuh tanpa koneksi internet (offline-capable).
03

Penyimpanan Data Lokal & Mekanisme Penghapusan Total

Karena data disimpan di direktori internal aplikasi (Android Sandbox / SQLite), Anda memiliki kendali otonom kapan pun ingin menghapus seluruh jejak riwayat:

phone_android
Pembersihan Internal di Perangkat

Buka Pengaturan Perangkat > Aplikasi > Homas > Penyimpanan > Hapus Data. Seluruh inventaris, foto, dan preferensi terhapus seketika dan tidak dapat dipulihkan.

delete_forever
Penghapusan File Cadangan Google Drive

Anda dapat mengakses aplikasi Google Drive Anda sendiri dan menghapus folder cadangan Homas kapan saja tanpa memerlukan izin atau keterlibatan pihak developer.

04

Monetisasi, Iklan & Kepatuhan app-ads.txt

Untuk versi gratis/didukung iklan, Homas dapat menggunakan layanan iklan resmi bersertifikasi Google AdMob. Penyedia iklan pihak ketiga dapat memproses pengidentifikasi perangkat anonim sesuai dengan regulasi Google Play Developer Policy.
