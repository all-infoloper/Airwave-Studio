Pencadangan Mandiri

Hubungkan Akun Google untuk Ekspor & Cadangan

cloud_sync Rekomendasi

Masuk ke menu Pengaturan > Sinkronisasi Cloud. Pilih 'Hubungkan Google Drive'. Berikan izin penyimpanan file spreadsheet/cadangan ke folder pribadi Anda. Homas tidak pernah membaca file lain di Drive Anda.

Prosedur Penghubungan Cloud
FASE 1 settings
Buka Pengaturan

Pilih menu tab pojok kanan bawah lalu klik Cloud Storage.

FASE 2 add_to_drive
Pilih Google Drive

Gunakan akun Gmail aktif Anda lewat prompt login Google.

FASE 3 folder_special
Folder Khusus

Folder /Homas-Backup/ dibuat otomatis di Drive Anda.

lock_clock
Izin Terbatas (Restricted Scope)

Otorisasi OAuth Homas hanya meminta hak akses drive.file. Artinya, aplikasi TIDAK BISA membaca foto, dokumen kerja, atau spreadsheet lain yang sudah ada di akun Google Drive Anda.

Pertanyaan Umum (FAQ)

Apakah data saya hilang jika ganti HP baru? expand_more

Tidak, asalkan Anda sudah menghubungkan Google Drive pada HP lama dan menekan tombol "Cadangkan Sekarang". Di HP baru, cukup unduh Homas, login dengan akun Google yang sama, lalu tekan tombol "Pulihkan dari Drive".

Bisa digunakan tanpa akun Google sama sekali? expand_more

Sangat bisa! Homas dirancang offline-first. Anda dapat menggunakan seluruh fitur inventaris tanpa koneksi internet dan tanpa akun apa pun. Cadangan database juga dapat diekspor secara manual berupa file JSON/ZIP ke kartu SD Anda.

Butuh Bantuan Lebih Lanjut?

Pelajari arsitektur privasi kami atau tanyakan kendala penggunaan langsung kepada tim pengembang.
